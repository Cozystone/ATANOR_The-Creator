# 로드맵 (2026-11-21 밤, 창립자 승인)

완성의 정의: 하나의 자아가 하나의 세계에서 이어서 살고, 제 겪음으로 자라며, 노트북 한 대에서 산다 (키우는 것은 고사양 PC).
판정 눈금은 행동으로 드러나는 네 표지: (1) 제 탓과 세계 탓을 가른다 (2) 하나로 이어진다 (3) 제 몸을 알아본다 (4) 시키지 않은 것을 한다.

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 속마음 (숨은 것을 들고 있는 속 상태) | 네 판 실패 → 빠른 저장소 쪽으로 방향 바꿈 |
| 1과 나란히 | 귀 / 보호받는 어린 시절 / 표지 1 측정 | 표지 1 첫 눈금 0.73 (0.5 = 못 가름). 귀는 결함 고치는 중 |
| 2 | 빠른 기억 + 느린 굳힘 (해마와 피질처럼) | **길의 기억으로 첫 통과: 삶마다 나아짐, 망각 없음** |
| 3 | 하나로 이어 살기 (몸 하나, 세계 하나, 끊기지 않는 삶) | 대기 |
| 4 | 다른 존재: 남을 보고 배우기 | **실험 중** (어른이 먹는 길을 보고 적기) |
| 5 | 스스로 줄여 담기 + 연속 조절 몸 | 대기 |
| 6 | 걸음 거리 배우기 (지은 지도 떼기) | 대기 |
| 7 | 제 몸 알아보기 | 대기 |
| 8 | 감정의 번짐, 소리 신호 (말은 돋아나는지만 본다) | 대기 |
| 9 | 넓은 세계: Crafter로 다시, Minecraft, 컴퓨터 화면, 사람의 모습 | 대기 |
| 10 | 세대 | 대기 |

매 단계 붙는 관문: 손으로 준 것의 장부 / 다른 세계로의 이월 / 지은 것 옆에 배운 것을 나란히 / 씨앗 둘 이상 / 네 표지에 비춰 보고.
