# ATANOR — The Creator

> 몸과 결핍을 가진 작은 존재가, 스스로 겪은 것으로 자라는가.
> *Does a small being with a body and needs grow from what it lives through?*

ATANOR는 언어 모델이 아닙니다. 말도, 이름표도, 바깥에서 준 목표도 마음에 넣지 않습니다.
1인칭 3D 세계에 몸 하나를 두고, 그 몸이 **목마름과 배고픔**이라는 바탕 하나만 가진 채
눈으로 보고, 기억하고, 찾아가고, 실패하고, 다시 찾는 과정을 기록합니다.

이 저장소는 그 연구의 **1인칭 3D 세계 단계**(2026-11-20 밤부터)를 담습니다.
그 앞의 단계(격자 세계, Crafter)는 별도 기록에 있습니다.

## 지금 어디까지 왔나 (2026-11-21 기준)

| 된 것 | 숫자 |
|---|---|
| 그림만 보는 눈(가운데 곱게, 주변 거칠게)으로 샘을 찾아 먹기 | 작은 방에서 끝까지 사는 삶 83~86% |
| 헛되면 놓기 (내다본 풀림이 오지 않은 행동은 덜 끌림) | 같은 존재가 44% → 94% |
| 길의 기억: 신경망을 고치지 않고 겪은 길을 적어 다시 쓰기 | **여덟 삶 동안 삶마다 나아짐 (+26%)**, 기억 없는 쪽은 그대로 |
| 덜 걸어 본 쪽으로 가기 | 끝까지 사는 삶 약 10배 (0.4% → 4.8%) |
| 세계와 눈을 GPU로 | 초당 15만 몸-틱 (CPU 방식의 약 190배) |

| 안 된 것 (정직하게) | |
|---|---|
| 순간에서 순간으로 이어지는 속마음이 숨은 것의 자리를 담기 | 네 가지 방식 모두 실패 (5~7%) |
| 살면서 신경망을 고치기 | 네 가지 방식 모두 옛 것을 잊음 |
| 큰 미로에서 오래 살기 | 아직 낮음. 가장 잘 사는 꼴은 지은 기관(자리 목록, 지도)에 기댐 |

자세한 경과와 모든 실패는 [`docs/RESEARCH_LOG.md`](docs/RESEARCH_LOG.md)에 있습니다.

## 구조

```
atanor_os/emerge/
  core.py         마음의 알맹이 (세계의 이름이 없다): 내다보기, 풀림의 기억(크기 고정), 끌림, 헛됨
  room3d.py       1인칭 3D 세계 (시계로 흐름, 저장고가 줄어듦, 벽, 샘이 옮겨 감)
  room3d_live.py  몸과 감각: 눈(Retina: 초점과 고리, 눈의 반사), 귀, 자리 기억, 걸음 셈, 삶의 고리 (CPU)
  room3d_map.py   머릿속 지도 (모름 / 트임 / 막힘 + 언제) 와 속으로 걸어 보기
  routes.py       길의 기억 (CPU)
  room3d_gpu.py   세계 + 그림 + 눈을 몸 수천 개에 대해 GPU에서 한꺼번에
  roads_gpu.py    길의 기억 (GPU)
  life_gpu.py     GPU에서 사는 고리 (얼린 알맹이 + 헛됨 + 길의 기억 + 덜 걸어 본 쪽)
  social_gpu.py   두 몸이 한 세계를 나눔: 남이 먹는 것을 보고 그 길을 제 기억에 적기
  inner.py        속마음 (이어지는 속 상태, 행동 묶음을 눈 감고 내다보기) - 실험 중
  plastic.py      살면서 고치기 (되새김 + 느린 나) - 해로움이 확인됨, 기록용
  room3dwatch.py  실시간 뷰어 (존재의 눈앞, 눈이 받는 것, 위에서 본 세계, 머릿속 지도, 마음 안의 신호)
atanor_os/eye/fovea.py   눈 기관 (가운데 곱게, 주변 거칠게, 주변의 센 빛깔 남기기)
experiments/              판정에 쓴 실험 스크립트
models/                   판정에 쓴 존재들 (작은 파일)
docs/                     연구 기록, 로드맵, 원칙
docs/history/             개발 역사 전체 (기록만): 처음부터의 모든 계획·결과 문서와 커밋 기록. 코드는 이 단계 것만 넣었다
```

## 돌려 보기

```bash
pip install torch numpy pillow opencv-python
# 뷰어 (http://127.0.0.1:8769)
python -m atanor_os.emerge.room3dwatch --pointer viewer3d.example.json --port 8769
# 핵심 판정: 길의 기억이 삶마다 나아지는가 (GPU)
python experiments/roadgpu.py models/room3d_ret4r.pt 8192 8 1500 1
```

## 원칙 (요약)

- 마음 안에 말·이름표·바깥 목표·계획기를 넣지 않는다. 바람은 지어 주지 않고, 진화가 준 작은 바탕에서 돋아나게 한다.
- 기억은 크기가 고정이다. 겪을수록 자라지 않는다.
- 의식이나 느낌을 주장하지 않는다. 행동으로 드러나는 표지만 잰다.
- 손으로 준 것은 장부에 적고, 하나씩 뗀다 (보조바퀴).
- 키우는 곳은 고사양 PC, 사는 곳은 노트북 한 대.
