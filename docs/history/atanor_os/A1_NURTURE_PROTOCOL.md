# D19: a nurture stage - the T room grows with the being (registered 2026-11-24, before running)

## Why
D1-D18: no value target or read-out makes the being's value steer by need. Root measured in the lived rings: a fill almost never happens when that
store is the lower one (0-8%); the being camps at one spring and dies of the other lack (13-17 deaths per 12,000 beats). The experience
"I lacked it, went, and it was relieved" is nearly absent, so nothing can learn it. D18: with the pull silenced the value alone steers at chance.
Precedent in this project: E20 needed an easy-body stage first, and staged grow-on lifted survival 3% -> 80% (founder: nurture stage, removed gradually).
Prior work: curricula where the world grows with the learner (POET, Wang et al. 2019; Elman 1993, starting small).

## Design (world / nurture property, no change in the being, no behaviour rule)
Same being file (atanor.pt, as it lives now), cued depletion world, the same total of 12,000 lived beats per layout, dev 9101-9103 x mirror:
- flat (control, already recorded): the full-size T room for all 12,000 beats (probe-work/a1cache_cues).
- graded: the same T layout with the stem, arms and legs scaled to 25%, 50%, 75%, 100% of their lengths (at least 1 cell), 3,000 beats each; the being is
  carried from one room to the next (a cut; memory and learning continue).
Measured in the life: fills where that store was the lower one (need-directed fills), deaths, per stage; and for the flat control the same from its ring.
Then the A1 v2 fork in the full-size room with the life's own value, the relief-share arm (D17) trained offline on the graded ring, and its shuffled control.

## Reading (fixed now)
Graded life: need-directed fills in the last (full-size) stage at least 3x the flat life's per-3,000-beat rate AND deaths lower; fork: the life's own value
or the relief arm first match >= .65 and >= .10 above the shuffled control, recovery above the flat life's (a1_v3: .21) by >= .10.
Both -> nurture staging is how the being gets the experience; next = all 12 dev layouts, then the sealed seeds once.
Life better but fork not -> the experience is there but the value still does not use it (then the value organ is the remaining break, with real data to learn from).
Life not better -> the room size is not the limit (look at what keeps it at one spring: the pull and the hold).
