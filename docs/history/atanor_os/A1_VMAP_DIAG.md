# D6: the value along the arms (registered 2026-11-24, before running)

D5 falsified aliasing: a linear read of the feelings tells the left and right arm apart perfectly (1.00, 6 layouts). Yet the state value does not rate
the needed arm above the other (D4 follow-up: .05). So: does the value rise toward the spring the body needs?

Judge places clones at cell centres along both paths (junction -> crossbar -> down leg -> the cell before the spring), facing along the path toward
the spring, with thirsty (water .30, food .95) or hungry (.95 / .30) stores. Values read: the offline state value (D4's), the lived action value's max,
arm 3's score max. Per layout x need: V at each step for the needed path and the other path; reported: slope toward the needed spring
(last cell minus junction), and the needed-minus-other gap at matched distance.
Reading: no rise and no gap = the value never learned where relief comes from (look at the reward stream and the learning itself);
a rise on both paths with no need dependence = it knows 'springs are good' but not 'the needed spring'; a need-dependent rise = the state value is
right and the failure sits in turning it into a choice at the junction.
