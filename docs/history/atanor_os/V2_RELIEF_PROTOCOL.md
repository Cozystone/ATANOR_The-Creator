## One change

(pull, hold, try, trust as they are; the value starts untrained in this body and earns its trust by its own record).

# V3 (registered before running): sleep consolidation
Brains consolidate value in sleep by replaying lived experience (hippocampal replay, e.g. Mattar & Daw 2018; Kumaran, Hassabis & McClelland 2016).
One change from V2: every 3,000 beats the 64 bodies rest (no stepping, a world schedule like night) while the mind replays its own ring for 2,500 value updates
(the same updates it makes awake, only more of them at rest; bedrock only, no rule). Same A/B and adoption criteria as V2 (deaths -20% vs control,
need-directed fills x2, junction fork first >= .65 and recovery >= .50), dev 9101-9103 x mirror; sealed seeds only after a pass.

# V4 (registered before running): who decides, by each one's own track record
Prior work: arbitration between habitual and goal-directed control by reliability (Daw, Niv & Dayan 2005). One change from V3: the relief pull gets a track
record like the value's earned trust (correlation of its strongest score with the wholeness change over the next 60 beats); on a strong-pull beat the value
decides with probability e_value / (e_value + e_pull). No hand-set weight. Mind(arbitrate=True), default off.
Same A/B and adoption criteria as V2/V3 (deaths -20% vs the worth control, need-directed fills x2, junction fork first >= .65 and recovery >= .50), plus
the stem fork (thirsty / hungry clones at the bottom of the stem, where life starts) reported. Dev 9101-9103 x mirror; sealed seeds only after a pass
including the A1 gate.
