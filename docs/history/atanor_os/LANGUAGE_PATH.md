# 말과 글로 가는 길 (2026-11-22, 창립자 요청: 사람이 말을 어떻게 깨우쳤나, 우리 안에서 말 그리고 글자까지 잘 이어질 길)

원칙 (바뀌지 않음): 마음에 글자나 사전을 넣지 않는다. 소리가 글보다 먼저. 어른(로컬 SLM, 나중에 Claude)은 마음 밖에 있고 장부에 올라 차츰 뗀다.
LLM처럼 말을 흉내 내는 것이 아니라, 몸과 겪음에 뿌리내린 말이 생각의 도구가 되게 한다.

## 1. 한 사람이 말을 깨우치는 차례 (발달)

| 때 | 일어나는 일 | 근거 (대표) |
|---|---|---|
| 태어나기 전 ~ 몇 달 | 엄마 말의 가락(운율)을 알아듣고 좋아함 | DeCasper & Spence 1986 |
| 0-12개월 | 소리의 통계를 배움: 자주 붙어 나오는 소리 조각이 낱말 (전이 확률로 낱말 경계 찾기). 모국어 소리 범주로 듣기가 좁혀짐 | Saffran, Aslin & Newport 1996; Kuhl 2004; Werker & Tees 1984 |
| 6-10개월 | 옹알이 (바-바-바): 제 성대·입을 움직여 제 귀로 듣고 잇는다 (몸으로 소리를 배움). 귀가 안 들리면 늦어짐 | Oller 2000 |
| 9-18개월 | 공동 주의: 어른의 눈길을 따라 같은 것을 봄, 가리키기. 아기가 이미 보는 것에 어른이 이름을 붙일 때 가장 잘 배움 (따라가며 이름 붙이기). 홀로 들린 낱말이 배움을 앞당김 | Tomasello & Farrar 1986; Baldwin 1991; Brent & Siskind 2001 |
| 약 12개월 | 첫 낱말. 낱말은 '것 전체'를 가리킨다고 가정, 새 소리는 아직 이름 없는 것에 붙임 (상호 배타) | Markman 1990 |
| 18-24개월 | 낱말이 폭발하듯 늘어남. 두 낱말 전보식 ("엄마 물", "양 가") | Brown 1973 |
| 2-4세 | 문법: 자주 쓰는 틀에서 일반화 (쓰임에 바탕). 문장 틀이 새 낱말의 뜻을 알려 줌 | Tomasello 2003; Gleitman 1990 |
| 3-7세 | 혼잣말 (소리 내어 스스로에게) -> 속말. 말이 계획과 생각의 도구가 됨 | Vygotsky 1934; Fernyhough 2016 |

핵심: 말은 (a) 이미 몸으로 가른 개념 조각 위에, (b) 같은 것을 함께 보는 어른의 소리로, (c) 제 소리를 내고 듣는 몸으로, (d) 남을 움직이는 쓰임에서 자란다. 문법은 맨 뒤.

## 2. 종으로서 사람이 말을 얻은 길 (진화, 짐작이 섞인 분야)
- 몸짓과 흉내: 남의 행동을 제 몸의 행동으로 비추는 체계 (거울 뉴런)가 몸짓 소통으로, 다시 소리로 (Rizzolatti & Arbib 1998).
- 함께 하려는 마음: 같은 목표를 함께 보는 협력 의도가 가리키기와 말의 바탕 (Tomasello 2008).
- 무리가 커지며 털고르기 대신 말 (Dunbar 1996).
- 소리를 배워 낼 수 있는 몸 (성대·입의 섬세한 조절, 새와 사람과 몇 종만): 들은 소리를 흉내 내는 바탕이 진화함 (Jarvis 2004). 노래새는 타고난 '본보기 틀'과 제 소리를 견주며 배움.
- 기호의 문턱: 소리가 것을 가리키는 것(지표)을 넘어, 소리끼리의 관계가 체계를 이룰 때 기호가 됨 (Deacon 1997).

우리에게 주는 것: 진화된 바탕은 (1) 남을 비추고 흉내 내는 바탕, (2) 들은 소리를 제 소리로 맞춰 보려는 바탕, (3) 함께 보기. 이것들이 고정할 수 있는 '바탕' 후보이고, 낱말 자체는 겪음에서.

## 3. 글자 (역사와 한 사람의 배움)
- 역사: 셈을 위한 흙 토큰 -> 그림 글자 -> 소리 빌리기 (그림을 그 소리로 읽기, 레버스) -> 음절 글자 -> 자모 (Schmandt-Besserat 1992). 글은 '말소리를 눈에 보이게 남긴 것'.
- 한글: 자음은 소리 낼 때 발음 기관의 꼴을 본떴다 (ㄱ 혀뿌리가 목을 막는 꼴, ㄴ 혀끝이 잇몸에 닿는 꼴, ㅁ 입, ㅅ 이, ㅇ 목구멍), 획을 더하면 소리가 세짐, 모음은 하늘·땅·사람 (훈민정음 해례 1446). 소리를 내는 몸과 글자의 꼴이 이어진 드문 글자 - 몸에 뿌리내린 글자 배움에 꼭 맞다.
- 한 사람의 읽기: 이미 있는 것 알아보기 회로를 글자 알아보기로 다시 씀 (신경 재활용, 시각 낱말 영역, Dehaene 2009). 소리와 글자의 짝을 익힌 뒤 (파닉스) 자동이 된다. 글은 말 위에 얹힌다 - 말 없이 글부터 배우지 않는다.

## 4. 우리 길 (단계, 관문, 손으로 준 것)

| 단계 | 하는 것 | 통과 관문 (스스로 이어졌는가) | 손으로 준 것 (장부) |
|---|---|---|---|
| L0 소리 듣기 | 귀 (게임의 진짜 소리, 띠 16). 다음: 소리 요약을 JEPA 꼴로 스스로 배움 (소리 조각, 낱말 경계는 통계로) | 같은 소리를 같은 요약으로 묶음 (라벨 없이 무리 짓기) | 띠의 로그 간격 |
| L1 개념 조각 | 사물 쪼개기 (움직임, 깊이, 슬롯) | 것마다 따로 된 요약, 배경이 바뀌어도 같은 것 | 시작 단서 |
| L2 어른의 이름 | 목소리 어른 v0: 아기가 보는 것에 전보식 어근 ("양", "나무", "좀비, 위험") | 소리만 듣고 그 것의 꼴을 떠올림 (소리 -> 눈 요약 내다보기가 우연보다 뚜렷이 나음) | 어른, 어른의 말 목록, 위험한 것 목록, 차츰 뗌 |
| L3 발성 기관 | 몇 매개변수 (높낮이, 모음 꼴 두 갈래, 세기, 길이)로 소리를 내는 몸짓 갈래. 제 귀로 들음. 바탕 후보: 들은 소리와 제 소리를 맞춰 보려는 끌림 (노래새의 본보기 견줌) | 어른의 낱말 소리를 흉내 내어 닮게 냄 (스스로, 보상 점수 없이) | 성대 합성기의 꼴 |
| L4 소리로 남을 움직임 | 여러 존재가 한 세계에: 경고 소리 (버빗원숭이처럼), 부름 | 한 존재의 소리에 다른 존재가 그 것 쪽을 봄 / 피함 | 여러 몸을 한 세계에 |
| L5 낱말 둘 | 것 + 몸짓 ("양 먹", "나무 캐") - 어른도 두 낱말로 | 처음 듣는 조합에 맞게 움직임 / 냄 | - |
| L6 속말 | 제 소리를 밖으로 내지 않고 상상 (세계 모델)에 넣어 굴림 | 소리 기호로 굴린 계획이 그림으로 굴린 것보다 더 길게 맞음 (생각의 도구) | - |
| L7 글자 | 한글의 원리로: 어른이 글자를 보여 주며 소리 (공동 주의에 글자를 더함). 제 발성 기관의 꼴과 글자의 꼴을 잇기. 존재가 세계에 표시를 남기고 (블록 놓기, 긁기) 다시 보고 소리를 떠올림 | 처음 보는 글자 조합을 소리로 읽음 / 표시를 남겨 남에게 알림 | 글자를 보여 주는 판 |

순서의 이유: 개념 조각 (L1)이 없으면 소리가 장면 전체에 붙어 엉킨다. 발성 (L3) 없이도 듣고 잇기 (L2)는 된다 (아기도 말하기 전에 알아듣는다). 글자 (L7)는 말 위에.
지금 위치: L0 (귀) 붙음, L2의 배관 (목소리 어른) 만듦. L1 (사물 쪼개기)이 다음 단계의 문.


## 5. 코드를 징검다리로 (창립자 2026-11-22, 구체화) - 몸의 인과 -> 컴퓨터 언어 체화 -> 어른과 코드·말 짝짓기 -> 사람 말

원칙과 맞추기: 코드는 마음에 넣는 기호가 아니라 **세계를 바꾸는 몸짓**이다 (단추를 누르는 손처럼). 마음 안에는 여전히 이름표가 없고, 기호는 '누르면 방이 이렇게 바뀐다'는 겪음으로만 뜻을 얻는다 (기호 접지). 소리가 글보다 먼저라는 차례도 그대로 (어른의 말은 소리로, 글자 꼴은 맨 뒤).

### 5.1 터미널 기관 (보편 몸 계약 안에서)
- 움직임 갈래 하나를 더함: '낱자 누르기' (K개, 처음엔 12쯤) + '실행' + '지우기'. 한 걸음에 낱자 하나 (사람이 자판을 하나씩 치듯).
- 감각 갈래 하나를 더함: 터미널 화면을 **그림으로** (지금까지 친 낱자들이 그려진 작은 판) - 존재는 그것을 제 눈 (작은세포 갈래)으로 본다. 낱자의 '이름'은 주지 않는다.
- 실행의 결과는 따로 알려 주지 않는다: 방이 바뀐 것을 제 눈·살갗·몸 안으로 겪을 뿐.
- 낱자 (존재에게는 그냥 모양이 다른 단추): 동사 넷 (만들다, 없애다, 열다, 옮기다), 대상 넷 (먹이, 물, 벽/문, 빛), 자리 넷 (앞, 왼쪽, 오른쪽, 멀리). 문법은 '동사 대상 자리'.
- 샌드박스: 효과는 실험방 안에서만, 곧바로, 늘 같게 (결정적). 숙주의 실제 체계 (파일, 명령줄, 네트워크)에는 절대 닿지 않는다.

### 5.2 단계와 관문
| 단계 | 하는 것 | 통과 관문 (스스로 이어졌는가) |
|---|---|---|
| T0 단추 하나 | 낱자 하나 + 실행 = 효과 하나 (예: '먹이' 단추 -> 앞에 먹이). 몸 옹알이처럼 아무거나 눌러 봄 | 배고플 때 먹이 단추를 고르는 몫이 우연보다 뚜렷이 높음 (값 기관이 바탕으로 배움) |
| T1 두 낱자 짜맞춤 | '동사 + 대상' | **처음 쳐 보는 짜맞춤의 결과를 내다봄** (예: '만들다 먹이', '없애다 물'만 겪고 '만들다 물'의 결과를 맞힘) = 짜맞춤의 일반화 (진짜 기호 접지의 표지) |
| T2 차례와 계획 | '열다 문' 다음 '옮기다 먹이'처럼 둘 이상을 차례로 | 상상 (값으로 매기는 여러 걸음 굴림)으로 처음 보는 목표를 짧은 명령열로 이룸 |
| T3 어른과 짝짓기 | 어른 (로컬 SLM, 뒤에 Claude: 장부)이 (a) 존재가 실행한 것을 우리말 소리로 말해 줌 ('먹이 만들었네'), (b) 사람 말의 부탁 ('문 열어')을 듣고 코드를 쳐서 보여 줌 | 어른의 말소리만 듣고 맞는 명령을 침 (알아들음) - 세 조건: 말 있음 / 없음 / 뒤섞은 말 |
| T4 말하기·글자 | 존재가 제 발성 기관 (L3)으로 명령을 말로 냄 / 터미널 낱자 꼴을 한글로 바꿔 소리와 글자를 잇기 (L7) | 처음 듣는 말 조합을 맞는 명령으로 옮김; 제 소리로 어른이 대신 치게 함 |
| (R6-R7) 거울 방 | 같은 명령 체계로 제 복제본의 설정을 바꿔 보고 결과를 봄 | 바꾼 것과 복제본의 달라짐을 내다봄 (자기 이해의 첫 꼴) |

### 5.3 왜 이 차례인가
- 코드는 뜻이 흔들리지 않는 순수한 인과 언어라 유아기 존재에게 사람 말보다 쉽다. 같은 명령 = 늘 같은 결과.
- 짜맞춤 (T1)이 진짜 시험이다: 외운 짝은 기호 접지의 증거가 아니고, 처음 쳐 보는 짜맞춤을 맞힐 때만 '기호가 세계를 가리킨다'를 몸으로 안 것.
- 어른의 말은 그 위에 얹힌다 (T3): 사람 말이 '이미 몸과 코드로 겪은 인과'를 가리키게 되어, 빈 글자 흉내가 아니다.
- 소리-것 잇기 (L2)는 이와 나란히 자란다 (어른의 '양', '물'). 사물 쪼개기 (R1 무렵)가 둘 모두의 문.

### 5.4 손으로 준 것 (장부)
낱자의 개수와 문법, 샌드박스의 효과 목록, 어른 (SLM/Claude)과 그 말 목록. 위험: 명령이 숙주 체계에 닿는 일은 구조로 막는다 (방 안의 효과 표만 부를 수 있음).

### 5.5 지금 순서에서의 자리
