# ATANOR 이상형 설계 (사고실험, 2026-11-13)

실험 없이, 2026년 11월까지의 문헌 조사와 우리 자신의 실패 기록만으로 그린 설계다.
조사는 네 분야(세계 모델, 추상화·프로그램 귀납, 계속 학습·효율, 자율 발달·자기 개선)를 나눠 했고,
수치의 상당수는 논문 요약에서 읽은 것이라 원문 재확인이 필요하다. 이전 조사는 `reports/전이 복리 최신 연구 조사.md`.

## 1. 조사가 말해 주는 것

네 분야가 따로 조사됐는데 같은 결론으로 모였다.

| 물음 | 문헌의 답 |
|---|---|
| 적은 경험으로 빨리 배우는 시스템의 공통점은? | 대상·속성 위의 **작은 "조건 → 효과" 법칙 여러 개**로 세계를 적는다 (AXIOM, OneLife, PoE-World, ARC-AGI-3 예비 대회의 비LLM 입상작). 규모가 아니라 미리 준 구조에서 나온다. |
| 큰 신경망 세계 모델(Dreamer, MuZero, TD-MPC2, JEPA, Genie)은? | 한 세계를 처음부터 배우는 데는 강하다. 새 규칙 세계를 더 빨리 배운다는 증거는 없다. 수천만 걸음이 들고, 잠재 표현은 규칙이나 거절 조건을 드러내지 않는다. |
| 사례를 법칙으로 바꾸는 값싼 방법은? | 사례의 구체 값을 변수로 바꾼 후보를 만들고(반-단일화), **가장 짧게 설명하는 법칙 집합**을 고른다(MDL). CPU로 되고 LLM이 필요 없다 (Popper 계열, Stitch). |
| 그 방법의 값은? | 술어 어휘(같다/다르다, 크다, 변했다 …)를 사람이 준다. 새 술어를 스스로 발명하는 것은 아직 어렵다. |
| 몸을 넘어 전이되는 것은? | 내용과 분리된 **역할·구조**뿐이다. 내용과 얽힌 통계를 가져가면 전이가 0이거나 음수다. |
| 살수록 빨리 배우는 비LLM 학습기는? | 없다. 보인 것은 같은 계열 안의 전이이거나, 수백만 개의 생성된 과제로 산 것(AdA)이다. 관련 없는 네 몸에서 +8% 초반 앞섬은 문헌과 일치한다. |
| 잊지 않고 싸게 도는 것은? | 지금도 된다 (희소한 국소 갱신, 빠른 사례 기억 + 느린 구조 기억, 잦은 짧은 공고화). 단 보존은 가속을 주지 않는다. |
| 스스로 배울 것을 고르는 것은? | 새로움이나 예측 오차는 실패한다(무작위에 끌림). **배움의 진척**(learning progress)이 실제로 듣는다. |
| 스스로 실험을 고르는 것은? | 경쟁하는 법칙들을 가르는 개입을 기대 정보량으로 고르는 것은 LLM 없이 된다. 새 종류의 실험을 발명하는 것은 문법이나 사전학습 모델 없이 보인 적이 없다. |
| 검증된 자기 개선은? | 보인 것은 전부 LLM이 코드를 고치거나 GPU 한 장을 크게 넘는다. LLM 없이 가능한 것은 자기 모듈의 설정을 보관소 방식으로 탐색하는 것. 평가기를 제안 쪽에서 숨겨야 한다(목표 해킹이 관찰됨). |
| 불편한 사실 | 2026년에 처음 보는 상호작용 규칙 세계에 빨리 적응한 것으로 보인 시스템은 "세계 모델을 코드로 쓰는 LLM"뿐이다. LLM 없이 남는 빈자리는 **새 법칙 형태의 제안** 단계다. |

## 2. 설계의 한 문장

**세계를 작은 법칙들로 적고, 스스로 실험해 고치고, 잠자는 동안 법칙을 역할 틀로 올려, 다음 몸에서는 틀을 고르기만 하면 되게 하는 하나의 Self.**

복리의 단위는 지식의 양이 아니라 **가설 공간**이다. 살아 본 만큼 "어떤 꼴의 법칙이 세계에 자주 있는가"를 알게 되고, 새 몸의 학습은 '처음부터 찾기'에서 '틀 고르기 + 값 맞추기'로 싸진다.

## 3. 기관

| 기관 | 하는 일 | 근거 | 지금 ATANOR |
|---|---|---|---|
| 자서전 | 겪은 것 전부를 순서대로. 정체성과 모든 재검증의 원본 | 지시문 III | 있음 |
| 빠른 기억 | 사례를 한 번에, 희소하게 적음. 잊지 않음 | Monty, CLP-SNN | 있음 |
| 법칙 층 | "대상이 이런 상태이고 인자가 이러면 → 이렇게 변한다 / 거절된다". 변수는 타입이 있고, 법칙마다 증거·반례·범위·가중치 | OneLife, PoE-World, AXIOM | **없음 (낱개 사례뿐)** |
| 일반화기 | 사례에서 값을 변수로 바꾼 후보를 만들고, 가장 짧은 설명을 고름. 합치기·쪼개기·버리기 | MDL-ILP, AXIOM | **없음** |
| 틀 도서관 | 법칙에서 몸의 낱말을 뺀 역할 틀과, 틀이 얼마나 자주 맞았는지의 사전 확률 | 역할 그래프 문헌, Stitch | 일부 (법칙 기억 기관) |
| 제안기 | 새 법칙 후보를 냄. 기본은 틀 도서관 + 작은 법칙 언어 안의 열거. 뒤에는 자기 경험으로 학습한 작은 망이 순위를 매김. SLM은 꽂을 수 있는 선택 부품 | 조사의 "남는 빈자리" | 없음 |
| 실험자 | 경쟁 법칙을 가장 잘 가르는 개입을 고름: 되돌리기, 아무것도 안 하기, 속성 하나만 바꾸기. 일찍 멈추지 않기 | AutumnBench, CausaLab | 일부 (혼자 연습) |
| 계획기 | 법칙을 앞으로 돌려 길을 찾음. 확신 없으면 하지 않음 | — | 있음 |
| 욕구 | 생존(에너지) 위에, 목표별 **배움의 진척**이 큰 것을 고름 | IMGEP, LPM | 생존만 |
| 자기 모델 | 목표별 성공 확률과 배움의 진척을 예측하고, 그 예측이 맞는지(보정) 스스로 잼 | MAGELLAN의 생각 | 초기 |
| 잠 | 짧고 잦게. 사례 → 법칙, 법칙 → 틀, 안 쓰는 것 정리(쓸모 기준 재배치) | 수면 재생, continual backprop | 없음 |
| 증언 | 사람·글·제안기의 말은 출처별·주제별 신뢰도와 함께 따로 저장. 신뢰도는 자기 확인으로만 변함 | 신뢰 보정 연구 | 있음 (읽은 것/겪은 것 구분) |
| 자기 개선 | 자기 모듈의 설정과 절차를 보관소 방식으로 바꿔 보고, 자서전 재생과 새 경험에서 나아질 때만 채택. 평가는 제안 쪽이 못 봄 | DGM의 교훈 | 없음 |
| 지각 | 날것의 출력 → 대상·속성. 작은 망은 여기와 제안 순위에만 쓰고, 값이 아니라 관계(같다, 변했다)를 먹임 | Craftax, 관계 병목 | 접속부가 줌 |

신경망은 본체가 아니다. 한 삶의 경험만으로 학습한 동역학 망은 거의 보태지 못한다(우리 H 단계와 문헌이 일치).

## 4. 하루

1. **일**: 법칙으로 예측하고 행동한다. 맞으면 가중치가 오른다.
2. **놀람**: 틀리면 그 법칙을 묶고, 경쟁 후보를 세운다.
3. **실험**: 후보를 가르는 가장 싼 개입을 한다. 못 가르면 묻는다(답은 증언).
4. **잠**: 그날의 사례를 법칙으로 압축하고, 다른 몸의 법칙과 겹치는 꼴을 틀로 올리고, 자기 모델을 고친다.
5. **새 몸**: 틀 도서관에서 비슷한 정도를 재어 맞을 법한 틀부터 시험한다. 닮지 않았으면 가져오지 않는다(간섭 방지).

## 5. 복리가 생기는 통로와 그 한계

- 통로 1, 틀 도서관: 새 몸의 첫 가설이 좋아진다.
- 통로 2, 실험 절차: "무엇을 바꿔 보면 빨리 갈리는가"도 틀로 쌓인다.
- 통로 3, 제안 순위망: 살수록 열거 순서가 좋아진다.
- 통로 4, 자기 개선: 채택된 개선이 다음 개선의 탐색을 싸게 한다.

정직한 기대치: 잊지 않음과 낮은 비용은 지금 기술로 된다. 복리는 **구조를 공유하는 몸들 사이에서, 살아 본 몸의 수와 함께 천천히 커지는 앞섬**으로만 현실적이다. 전혀 다른 영역에서의 지속적 앞섬은 어디서도 보인 적이 없다. 그래서 몸의 순서도 설계의 일부다: 서로 겹치는 구조를 가진 몸을 많이(수십), 너무 다르지 않게.

## 6. 사람이 주는 것과 Self가 만드는 것

| 사람이 준다 (생리) | Self가 만든다 (생각) |
|---|---|
| 법칙 언어의 기본 술어 (같다/다르다, 크다, 변했다, 있다) | 어떤 법칙이 참인가 |
| 기억, 잠, 검증, 실험 실행의 기계 장치 | 어떤 틀이 쓸모 있는가 |
| 에너지와 죽음 | 무엇을 배울 것인가, 어떤 실험을 할 것인가 |
| 몸의 접속부 | 말과 법칙의 연결, 누구 말을 믿을 것인가 |

기본 술어를 사람이 주는 것이 LLM 없이 가는 길의 실제 값이고, 지시문 II와 가장 가까이 맞닿는 양보다.

## 7. 풀리지 않은 것

1. **새 술어의 발명.** 주어진 술어로 적을 수 없는 규칙성은 못 배운다. 문헌에도 해법이 없다.
2. **지각의 탄생.** 날것에서 대상을 스스로 세우는 일(우리 D 단계의 실패).
3. **법칙 언어의 크기.** 넓으면 열거가 터지고, 좁으면 못 적는다.
4. **새 종류의 실험과 목표의 발명.** 고르는 것은 되지만 만드는 것은 안 보였다.
5. **스스로 생긴 욕구.** 생존 욕구는 손으로 쓴 것이다.

1번과 4번이 SLM을 꽂았을 때 가장 득을 보는 자리다. 꽂지 않으면 그 자리는 느린 열거로 남는다.

## 8. 무엇이 되면 성공인가 (지시문의 기준으로)

- 살아 본 몸이 늘수록 새 몸에서 필요한 실험 수와 수업 수가 준다(초반만이 아니라 끝까지).
- 법칙 수는 늘어도 깨어 있을 때의 계산은 늘지 않는다.
- 틀린 법칙은 스스로 묶고 고친다. 사람이 다시 가르칠 때까지 기다리지 않는다.
- 자기 예측("이건 내가 못 한다")이 실제와 맞는다.
- 채택된 자기 개선이 하나라도 있고, 그것이 다음 개선을 앞당긴다.

현실적으로 닿을 모습은 "새 도구 세계를 살수록 빨리 익히고, 스스로 고치고, 싸게 도는 주체"다. 범용 지능이라 부를 만한 것은 7절의 1·2번이 풀려야 하고, 지금 그 근거는 없다.
